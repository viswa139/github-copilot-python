# GitHub Copilot Instructions

This is a Flask-based Sudoku game.

Guidelines:
- Keep the code modular and reusable.
- Follow Python PEP 8 standards.
- Do not duplicate code.
- Preserve existing functionality unless explicitly asked to change it.
- Use pytest for testing.
- Explain important code before implementing it.
- Keep HTML, CSS and Python files organized.
- Make changes incrementally and verify tests continue to pass.
- Do not remove existing functionality while adding new features.
